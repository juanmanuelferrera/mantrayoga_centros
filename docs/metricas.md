# Métricas

Se rellena el mismo día del taller, antes de irse a dormir. Si se deja para
luego, no se rellena.

## Qué se anota

- **Asistentes.** Cuánta gente vino.
- **Repetidores.** Cuántos habían venido ya a este centro. Es la métrica que
  importa.
- **Contactos.** Cuántos dejaron el nombre para el aviso del mes siguiente.
- **Donativo.** Solo para saber si cubre gastos de desplazamiento.
- **Nota.** Una línea. Qué funcionó y qué no.

## Umbrales

- **Repetición por debajo del 33%:** el problema está en el taller. Revisar el
  guion antes de abrir centros nuevos.
- **Menos de 8 asistentes dos veces seguidas en el mismo centro:** el centro no
  lo está anunciando. Hablar con el dueño antes de dejarlo.
- **Dos meses seguidos sostenidos en todos los centros activos:** se puede abrir
  uno nuevo.
